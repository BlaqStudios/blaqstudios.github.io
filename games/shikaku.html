How to Play

Every puzzle starts the same way: a grid dotted with numbers. Draw a rectangle around each number so its area matches that number exactly — no more, no less. Do that for every number, cover every cell, and the puzzle is solved.

  • 01 One rectangle, one number — never two, never zero.
  • 02 The rectangle's area must equal the number exactly.
  • 03 Rectangles can't overlap or leave any cell empty.
